The Go-To List is meant to play a dual role, as a shortlist and as a sort of secondary Roster list. That is probably not a great idea, and in the end they should be both merged somehow.  
At the very least, it should probably integrate the entity card on tooltip feature, so talent profile view can be accessed directly from here.

Talent is added via context menu (Right/Secondary click) on the Talent Tab, which supports multi-additions by selecting several rows at the same time and then clicking.  
The same talent can be added to several categories.  
It is pretty much an attempt to implement Football Manager's shortlisting feature.
